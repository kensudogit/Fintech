Ledger Guide — マルチエージェント / RAG 対話

自然言語操作・行動分析パーソナライズ・ナレッジDB連携を、LangGraph オーケストレーションで統括するデモです。 PostgreSQL のサンプルデータを画面に表示し、対話結果をプロファイル学習へ反映します。

Python · FastAPI LangChain · LangGraph PostgreSQL RAG Next.js Streamlit
ARCHITECTURE エンドツーエンド構成

意図分類 → 専門エージェント実行 → 応答統合。ナレッジは PostgreSQL + 埋め込み検索、行動はイベント履歴からプロファイル更新します。

  • UI — FastAPI 静的画面（本画面）· Next.js · Streamlit
  • API — FastAPI /api/v1/* · Swagger /docs
  • Agents — operations · personalization · knowledge（LangGraph）
  • DB — users · behavior_events · knowledge_documents · conversation_*
RECOMMENDED 最短の進め方

初回はサンプルデータ投入から始めると、ナレッジ一覧・行動イベント・対話履歴がすぐに確認できます。

  • 「サンプルデータを投入」で PostgreSQL にデモデータを登録
  • 下部のナレッジ DB / 行動イベント表で内容を確認
  • 例:「振込手数料について教えて」で knowledge エージェントを実行
  • 例:「家計の改善提案をして」で personalization を実行
  • 右カラムで Intent / Agents / Activity Score を確認

詳細利用手順

  1. 1. 起動確認

    API ヘルスと RAG ドキュメント数を画面右上で確認します。

    • Health: /api/v1/health
    • Docs: /docs
  2. 2. データ投入

    「サンプルデータを投入」または POST /api/v1/seed?force=true でデモデータを登録します。

  3. 3. 対話と確認

    チャット送信後、オーケストレーション結果とパーソナライズ提案が更新されます。

  4. 4. ダッシュボード確認

    GET /api/v1/dashboard 相当の情報が画面下部テーブルに表示されます。

ヒント: ヘッダーをドラッグしてパレットを移動できます。折りたたみは ▼、再表示は画面右上の「利用手順」ボタンです。
